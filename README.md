# Books/Movie Ideas

Here we'll keep screenplays, manuscript and other story ideas.

Each story will have the roughly following format depending on format and length:

```
multiverse-writing-project/
├── README.md                    # Master logline, project vision, and format goals
├── .gitignore                   # Ignores large output files like PDFs/DOCX
│
├── core-universe-bible/         # Central repository for world-building and lore
│   ├── rules_of_time_travel.md  # How Young Dryas -> Costco mechanics actually work
│   ├── world_history.md         # Younger Dryas civilization vs. modern world lore
│   └── ai_symbiosis_mechanics.md # Rules of the human/AI mutual survival link
│
├── character-vault/             # Shared character profiles across all formats
│   ├── the-time-traveler.md     # Caveman adapting to 21st-century retail logistics
│   ├── the-text-thread-woman.md # Tracking her, her future-self, and past-self personas
│   ├── human_host.md            # The human half of the symbiotic pair
│   └── ai_parasite.md           # The AI half (personality, limitations, access)
│
├── story-arc-01-dryas-costco/   # Sandbox for the Time Traveler story
│   ├── outline_novel_concept.md # Beat sheet for a potential comedy/fish-out-of-water novel
│   ├── script_pilot_draft.md    # Screenplay attempt (using Fountain or markdown script)
│   └── scratchpad.md            # Raw scene ideas and Costco dialogue snippets
│
├── story-arc-02-text-thread/    # Sandbox for the Future Selves story
│   ├── thread_chronology.md     # Visual map of the text thread (who texts when)
│   ├── short_story_draft.md     # Literary fiction / thriller format
│   └── screenplay_beats.md      # Sci-fi thriller script breakdown
│
├── story-arc-03-symbiosis/      # Sandbox for the Human-AI survival story
│   ├── dual_perspective_log.md  # Split-screen writing format (Human vs AI thoughts)
│   └── novella_chapters/        # Bulleted chapter files for a claustrophobic survival tale
│
├── media-and-assets/            # Visuals, flowcharts, and inspiration
│   ├── timeline_paradox_map.png # Flowchart showing how the text thread loops
│   └── lookbook_costco.jpg      # Visual aesthetic references
│
└── exports/                     # Where your compiled outputs live
    ├── novels/
    └── screenplays/
```
